PORE ANALYZER V3.1 - FIT TO SCREEN

Same pore detection as V3. No detection parameters/defaults were changed.

New:
- Fit image to screen (default ON)
- Optional manual display width
- Canvas/image are resized only for display
- Rectangle coordinates are converted back to original image pixels
- Micrometre measurements therefore continue to use the original image scale

Run:
    streamlit run app.py
